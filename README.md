# Карта компаний — My Company Map

Модуль Joomla для отображения офисов, филиалов и других точек на интерактивной карте Яндекса. Адреса и координаты задаются в настройках модуля; посетители могут выбрать город и перейти от карточки к метке.

## Возможности

- Несколько точек на одной карте и автоматический выбор масштаба.
- Карточки адресов, телефонов и переход к нужной метке.
- Фильтр по городам и кластеризация близких точек.
- Несколько независимых экземпляров на одной странице.
- Цвет меток, размеры карты, начальная точка и масштаб в настройках.
- Необязательный якорь для ссылки на карточку точки.
- Переопределение вывода в шаблоне Joomla и выбор альтернативного макета.
- Русский и английский языки; стандартные обновления Joomla.

## Требования

- Joomla 5.x с PHP 8.1+ или Joomla 6.x с PHP 8.3+.
- Ключ **JavaScript API Яндекс Карт**, подключённый в [кабинете разработчика](https://developer.tech.yandex.ru/). Условия и лимиты определяются тарифом Яндекса. В настройках ключа разрешите домен сайта, на котором работает модуль; для локального тестирования отдельно учитывайте локальный домен.
- Доступ посетителя к API и пакетам Яндекс Карт. Ключ используется в браузере: настройте ограничения домена в кабинете Яндекса. Геокодер для работы модуля не требуется.

## Установка

### По ссылке

В Joomla откройте **Система → Установка → Расширения → Установить по URL-адресу** и вставьте:

```text
https://github.com/shivayanamahom/mod_mycompanymap/releases/latest/download/mod_mycompanymap.zip
```

### Из архива

Скачайте `mod_mycompanymap.zip` на [странице релизов](https://github.com/shivayanamahom/mod_mycompanymap/releases) и установите его через **Система → Установка → Расширения**. Контрольные суммы опубликованы в `SHA256SUMS.txt`.

## Настройка

1. Создайте модуль сайта **«Карта компаний (Яндекс)»**, выберите позицию и страницы в привязке к меню.
2. Вставьте ключ JavaScript API Яндекс Карт.
3. На вкладке «Компании» добавьте название, адрес, телефон, город и координаты каждой точки. Координаты вводятся в формате `широта, долгота`, например `55.751574, 37.573856`. Порядок полей важен.
4. При необходимости укажите уникальный якорь, например `office`: ссылка `#office` прокрутит страницу к карточке и покажет точку на карте.
5. Задайте размеры, начальный центр и цвет меток, затем опубликуйте модуль.

При нескольких точках карта подбирает границы автоматически. Если API не загрузился, проверьте ключ, ограничения домена, тариф и сетевое подключение. После создания или изменения ключа Яндексу может потребоваться время на активацию.

## Переопределение макета

Стандартный вывод находится в `tmpl/default.php`. Создайте переопределение `templates/<ваш_шаблон>/html/mod_mycompanymap/default.php` средствами Joomla; для альтернативного макета добавьте файл в ту же папку и выберите его в дополнительных параметрах модуля. Макет получает `$companies`, `$uniqueCities`, `$scriptOptions`, `$params` и `$module`. Фильтр и оформление можно изменить в переопределении, сохраняя общую логику расширения.

Для собственных меток макет может передать `$scriptOptions['customMarker'] = true` до регистрации опций. Маркер получает класс `mycompanymap-custom-marker`; его внешний вид задаётся стилями шаблона. Сохраняйте идентификаторы контейнеров и атрибуты `data-placemarkid` для работы переходов.

## Обновления

Источник обновлений добавляется при установке и проверяется штатным механизмом Joomla: **Система → Обновления → Расширения**. Установочный пакет сохраняет настройки существующих модулей. После обновления проверьте собственные переопределения, если они используют внутреннюю разметку или JavaScript.

## Разработка

`tools/build.sh` создаёт версионный и стабильный ZIP в `dist/` и файл `SHA256SUMS.txt`. В папку архива помещаются только файлы расширения и документация.
